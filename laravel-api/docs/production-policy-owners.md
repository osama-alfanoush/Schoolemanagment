# Production Policy Ownership

These are accountable roles until named people are assigned by the deploying school.

| Decision | Accountable role | Proposed baseline | Approval required before |
|---|---|---|---|
| Backup RPO/RTO | Platform owner + school operations owner | RPO 15 minutes, RTO 4 hours | Pilot data import |
| Restore verification | Platform owner | Automated daily verification plus quarterly witnessed restore | Pilot |
| Grade calculation/finalization | Academic registrar | Explicit configured rounding/missing-work rules; two-step finalization | Grade pilot |
| Attendance correction | Attendance officer | 48-hour teacher window; reasoned admin correction afterward | Attendance pilot |
| Retention/legal hold | Privacy officer + legal reviewer | No destructive education/finance deletion pending approved schedule | Any live data |
| MFA recovery | Security owner + help-desk manager | Two-person approval for privileged recovery | Privileged pilot access |
| Incident command | School operations owner | Named primary and deputy, current contact tree | Pilot |
